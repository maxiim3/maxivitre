# Optimization: Hero Image Loading

## Description
L'image de la section hero est longue à charger. Optimiser le chargement pour desktop et mobile.

## Problème
Image Unsplash trop lourde causant des temps de chargement lents.

## Solutions possibles
- Optimiser la taille/qualité de l'image
- Implémenter du lazy loading
- Utiliser des formats modernes (WebP, AVIF)
- Responsive images avec différentes tailles
- Précharger l'image critique

- `pages/index.vue` (hero section)
