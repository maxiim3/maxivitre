# Feature: Analytics & Tracking

## Description
Implémenter le suivi des performances et conversions pour mesurer l'efficacité du site.

## Outils à intégrer

### Google Analytics 4
- **Événements personnalisés** : Clics devis, appels téléphone, formulaires
- **Conversions** : Devis complétés, appels générés
- **Audiences** : Segmentation Pro/Particulier
- **Attribution** : Sources de trafic vers conversions

### Google Tag Manager
- **Centralisation tags** : Gestion simplifiée
- **Déclencheurs** : Événements business (scroll, clics CTA)
- **Variables** : Données dynamiques

### Tracking spécifique
- **Appels téléphone** : `tel:+33778818583` avec événement GA4
- **Devis forms** : Étapes de conversion + abandon
- **Toggle Pro/Particulier** : Usage des segments
- **Zones géographiques** : Performance par zone

### Pixels publicitaires (optionnel)
- **Facebook Pixel** : Remarketing
- **Google Ads** : Conversion tracking

## KPIs à suivre
- **Taux de conversion** devis/visiteurs
- **Source #1** de génération de leads
- **Performance** segments Pro vs Particulier
- **Zones** les plus convertissantes
