# Feature: Pages légales

## Description
Créer les pages légales obligatoires pour la conformité juridique et RGPD.

## Pages à créer

### Mentions légales (`/mentions-legales`)
- **Éditeur** : MaxiVitre - Identification complète
- **Hébergeur** : Informations hébergement
- **Contact** : Adresse, téléphone, email
- **Activité** : Description services de nettoyage
- **TVA** : Numéro si applicable

### CGV - Conditions Générales de Vente (`/cgv`)
- **Services** : Description prestations
- **Tarifs** : Modalités de prix (zones, options)
- **Commande** : Processus devis → intervention
- **Paiement** : Modalités et délais
- **Annulation** : Conditions d'annulation
- **Garanties** : Assurance, qualité
- **Responsabilité** : Limitations, force majeure

### Politique de confidentialité (`/confidentialite`)
- **Données collectées** : Formulaires, analytics, cookies
- **Finalités** : Devis, communication, amélioration
- **Droits RGPD** : Accès, rectification, suppression
- **Conservation** : Durées de stockage
- **Transferts** : Sous-traitants (Google, hébergeur)
- **Contact** : DPO ou responsable

### Cookies (`/cookies`)
- **Types** : Techniques, analytics, marketing
- **Finalités** : Fonctionnement, statistiques
- **Consentement** : Gestion préférences
- **Durées** : Expiration par type

## Bannière cookies
- **Premier visit** : Consentement requis
- **Choix granulaire** : Par catégorie
- **Révocation** : Modification possible
